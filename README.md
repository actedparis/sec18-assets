# SEC18 assets

Public 3D models used by the ACTED SEC-18 vehicle-inspection Power App.

`hilux/focus-NN.glb`: white pickup with the ACTED logo on both doors and the 22 SEC-18 checkpoint
markers. Step 00 shows the whole vehicle; step NN (01-22) is turned and centred on checkpoint NN,
with that marker in amber. No inspection data is stored here.
