# SEC18 assets

Public 3D models used by the ACTED SEC-18 vehicle-inspection Power App.

`hilux/focus-NN.glb` is a generic white pickup with the ACTED logo and the 22 SEC-18 checkpoint
markers. Step 00 shows the whole vehicle; step NN (01-22) is turned and centred on checkpoint NN,
with that marker in amber. No inspection data is stored here.

The files are generated by `tools/build_hilux_glb.py` in the private SEC18 repository and loaded by
the app's 3D viewer from `https://raw.githubusercontent.com/actedparis/sec18-assets/main/hilux/`.
